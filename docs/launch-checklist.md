# Launch Checklist

## Build

- [ ] Run `npm install`.
- [ ] Run `npm test`.
- [ ] Run `npm run build`.
- [ ] Run `hugo --gc --minify`.
- [ ] Run `git diff --check`.

## Content

- [ ] Homepage title is `Hexzzle - Free Color Hive Puzzle Online`.
- [ ] Play page title is `Play Hexzzle - Color Hive Puzzle Game`.
- [ ] Guide page title is `How to Play Hexzzle`.
- [ ] Old `/posts/<slug>/` URLs still render.
- [ ] CNAME behavior is intentionally preserved.

## Game

- [ ] Classic mode starts instantly.
- [ ] Result panel shows score, best score, total Blooms, best chain, and longest group.
- [ ] Restart works with one click or tap.
- [ ] Share uses Web Share API where available.
- [ ] Share fallback copies text to clipboard.

## Trust And Safety

- [ ] No secrets or private tokens are committed.
- [ ] No login, payments, coins, gems, forced ads, or rewarded ads are present.
- [ ] No unsupported claims appear in title, H1, metadata, or primary copy.
- [ ] Privacy, terms, and contact pages are reachable.

## Future Daily Mode

- [ ] Define seed format.
- [ ] Keep daily mode static-compatible.
- [ ] Do not add a backend leaderboard without a separate privacy and abuse review.
